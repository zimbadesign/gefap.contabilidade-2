GEFAP — site HTML/CSS responsivo

Arquivos principais:
- index.html
- styles.css
- assets/ (imagens e ícones)

O menu mobile é feito somente com HTML + CSS, sem JavaScript.
Os textos são HTML real; as imagens são usadas apenas como elementos visuais/backgrounds.

Para publicar: envie todo o conteúdo desta pasta para a hospedagem, mantendo a estrutura de pastas.

SEO técnico aplicado:
- title e meta description otimizados
- canonical para https://gefap.com.br/
- meta robots e previews ampliados
- Open Graph e Twitter Cards
- dados estruturados Schema.org (Organization, WebSite, WebPage e Service)
- robots.txt e sitemap.xml
- textos alternativos e atributos de performance nas imagens
- preload do background principal
- backgrounds convertidos para WebP para melhorar velocidade/Core Web Vitals
- melhorias semânticas e de acessibilidade (aria-labelledby, aria-current e labels)
